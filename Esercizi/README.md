 # Esercizi SQL Server - Data Analytics

Esiste una sola cartella didattica per gli esercizi: `Esercizi/`.

La cartella è organizzata internamente per livello:

- `Base/`
- `Intermedio/`
- `Avanzato/`

Le correzioni sono contenute nello stesso file dell'esercizio, in una sezione `CORREZIONE GUIDATA`, così lo studente può prima tentare autonomamente e poi confrontare la soluzione.

Percorso: **Base → Intermedio → Avanzato**.
