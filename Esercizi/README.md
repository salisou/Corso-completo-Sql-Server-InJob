# Esercizi SQL Server - Data Analytics

Gli esercizi sono separati per livello:

- **Base**: SELECT, WHERE, ORDER BY, DISTINCT, TOP, LIKE, IN, BETWEEN, NULL.
- **Intermedio**: JOIN, GROUP BY, HAVING, CASE, aggregazioni e sottoquery.
- **Avanzato**: CTE, ranking, funzioni finestra, KPI, LAG/LEAD e report analitici.

Regola didattica: prima si risolve l'esercizio senza consultare la correzione, poi si confronta la soluzione e si verifica il risultato in SQL Server.
