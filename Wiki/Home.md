# Welcome to the Corso-completo-Sql-Server-InJob wiki!

Benvenuto nella Wiki del corso completo di **SQL Server e Data Analytics** di **Docente Moussa Salisou**.

## Obiettivo del corso

Il percorso accompagna lo studente dalle basi di SQL Server fino alla realizzazione di query professionali e analisi dei dati.

La progressione è:

**Base → Intermedio → Avanzato → Data Analytics → Progetto finale**

## A chi è rivolto

Il corso è pensato per:
- principianti assoluti;
- studenti che vogliono imparare SQL Server;
- sviluppatori backend;
- software developer;
- aspiranti Data Analyst;
- chi vuole preparare dati per Excel e Power BI.

## Metodo didattico

Ogni argomento viene affrontato con:

1. Cos'è
2. A cosa serve
3. Perché usarlo
4. Sintassi
5. Esempio base
6. Esempio professionale
7. Spiegazione del risultato
8. Errori comuni
9. Esercizio
10. Correzione

## Database utilizzati

### ScuolaDb

Scenario didattico principale con studenti, corsi, docenti, aule, iscrizioni, lezioni e voti.

### HR Analytics

Scenario orientato alla Data Analysis con dipartimenti, dipendenti, presenze e promozioni.
