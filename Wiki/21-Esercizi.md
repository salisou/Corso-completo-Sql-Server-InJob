# 21 - Esercizi

## Struttura
Nel repository esiste una sola cartella principale per gli esercizi:

Esercizi/ → Base / Intermedio / Avanzato

## Base
SELECT, filtri, ordinamento, TOP, LIKE, DISTINCT, BETWEEN, IN e NULL.

## Intermedio
JOIN, GROUP BY, HAVING, aggregazioni, CASE e subquery.

## Avanzato
CTE, ranking, window functions, KPI e query analitiche.

## Correzioni
Ogni file contiene anche la **correzione guidata**. Lo studente deve prima provare autonomamente e poi verificare la soluzione.
