# 01 - Introduzione al corso

## Cos'è SQL?

SQL significa **Structured Query Language**. È il linguaggio usato per lavorare con database relazionali.

## A cosa serve?

Permette di:
- creare database e tabelle;
- inserire dati;
- leggere dati;
- modificare dati;
- eliminare dati;
- collegare più tabelle;
- aggregare e analizzare informazioni.

## Perché impararlo?

SQL è una competenza fondamentale per sviluppatori, database administrator e Data Analyst.

## Percorso

Il corso parte da SELECT e CRUD e arriva a JOIN, subquery, CTE, window functions, KPI e analisi professionale dei dati.

## Primo esempio

```sql
SELECT *
FROM Studenti;
```

La query legge tutti i record della tabella Studenti.
